# TEAM TOXIIC Sitio Web Oficial

Bienvenido al sitio web oficial de **TEAM TOXIIC** - Más Que un Equipo. Un Estado Mental.

## 🎮 Sobre el Proyecto

Esta es la primera versión del sitio web oficial de TEAM TOXIIC, una organización de esports con una estética moderna y sobria. El sitio web presenta una identidad creativa, misteriosa y pulida que evita los temas típicos de gamers.

## 🚀 Características

- **Diseño Moderno**: Tema oscuro y limpio con acentos en verde neón
- **Animaciones Suaves**: Pantallas de carga personalizadas, transiciones y efectos hover
- **Layout Responsivo**: Optimizado para escritorio, tablet y dispositivos móviles
- **Elementos Interactivos**: Cursor personalizado, sistema de partículas y efectos de scroll
- **Videos de Fondo**: Videos rotativos con efecto de vidrio esmerilado
- **Estética Minimalista**: Enfoque en contenido esencial sin distracciones

## 🛠️ Stack Tecnológico

- **HTML5**: Marcado semántico y accesibilidad
- **CSS3**: Estilos modernos con animaciones y layouts grid
- **JavaScript Vanilla**: Funcionalidad interactiva y experiencia de usuario fluida
- **Google Fonts**: Familias de fuentes Orbitron e Inter

## 🎨 Design Philosophy

- **Color Palette**: Black (#0a0a0a), Off-white (#f5f5f5), Neon Green (#39ff14), Deep Purple (#8a2be2)
- **Typography**: Modern sans-serif with custom distorted headers
- **Aesthetic**: Dark mode by default, minimal icons, understated elegance
- **User Experience**: Smooth transitions, intuitive navigation, fast loading

## 🔧 Setup Instructions

1. Clone the repository
2. Open `index.html` in a modern web browser
3. No build process required - pure HTML/CSS/JS

## 📱 Responsive Breakpoints

- **Desktop**: 1200px and above
- **Tablet**: 768px - 1199px
- **Mobile**: 320px - 767px

## 🎯 Secciones

1. **Página Principal**: Sección hero con fondo animado de videos y CTA
2. **Nosotros**: Historia de origen con paneles cómicos interactivos

## ⚡ Características de Rendimiento

- Animaciones optimizadas con transformaciones CSS
- Eventos de scroll con debounce
- Intersection Observer para visibilidad de secciones
- Dependencias externas mínimas
- Assets comprimidos y optimizados
